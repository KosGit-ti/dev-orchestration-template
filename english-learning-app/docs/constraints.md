# 制約仕様（Constraints）

## 目的

本アプリが実行時に守る制約を定義する。本ファイルが仕様の正本であり、実装は本ファイルに追従する。

## 適用の原則

- 判断不能な場合は安全側に倒す（フェイルクローズ、P-010）。
- 制約判定は一箇所へ集約し、呼び出し側から回避できない構造にする。
- 警告だけ出して処理を続ける段を作らない。通すか止めるかのどちらかにする。

## 制約一覧

### C-001 学習コンテンツの言語

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| 許可文字 | 日本語（かな・カタカナ・漢字）を含まない | 第一目的（FR-001）・P-101 |
| 検査点 | `npm run validate:content` / 単体テスト / CI | 二重にして片方の抜けを補う |

- 判定：`content/**` の全文字列フィールドを走査し、`[぀-ゟ゠-ヿ一-鿿]` に一致したら fail。
- 理由コード：`C001_japanese_in_content`

### C-002 パスワードの保存形式

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| アルゴリズム | PBKDF2-HMAC-SHA256 | WebCrypto で利用でき、追加依存が要らない |
| 反復回数 | 600,000 以上 | OWASP 推奨（2023 年時点） |
| ソルト長 | 16 バイト（アカウントごとに異なる） | 同一パスワードのハッシュ一致を避ける |
| 保存内容 | ハッシュとソルトのみ | 素のパスワードを保存領域へ書かない（P-002） |

- 判定：`hashPassword` 以外の経路でパスワード文字列を保存しない。単体テストでハッシュ内に素のパスワードが現れないことを確認する。
- 理由コード：`C002_password_storage`

### C-003 パスワードの最低要件

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| 最小長 | 10 文字（前後の空白を除く） | 総当たりに対する最低限の抵抗 |
| 初期パスワード | 変更するまで学習画面へ入れない | 公開値のまま使わせない（FR-020） |

- 判定：`isAcceptablePassword` を認証プロバイダの全書き込み経路で通す。
- 理由コード：`C003_weak_password`

### C-004 管理者不在の禁止

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| 自己削除 | 禁止 | 管理者が消えると復旧手段が無くなる |
| 権限検査 | 全管理操作で actor の role を確認 | learner からの呼び出しを拒否する |

- 判定：`deleteAccount` は actor と target の一致を拒否する。管理操作は `requireAdmin` を通す。
- 理由コード：`C004_admin_lockout`

### C-005 進捗データの破壊的読み出しの禁止

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| 未知の version | 空の進捗へ倒す | 推測で読むと壊れた状態が続く |
| 破損 JSON | 読み出し失敗として扱う | 黙って上書きすると原因が消える |

- 判定：`migrate()` が既知の version 以外を受けたら、既存データを解釈せず空へ倒す。
- 理由コード：`C005_progress_schema`

### C-006 保存できない環境での挙動

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| localStorage 不可 | 学習は続行し、記録されない旨を警告する | 無言で捨てない |
| 認証 | `storage-unavailable` を返してログインさせない | 記録できない状態でログイン状態を作らない |

- 判定：`isPersistentStorageAvailable()` で実際に書き込みを試す。存在確認だけでは不十分（容量超過を検出できない）。
- 理由コード：`C006_storage_unavailable`

### C-007 出題の決定性

| パラメータ | 値 | 根拠 |
| --- | --- | --- |
| 乱数源 | seed 付き xorshift | `Math.random()` はテストで固定できない |
| 保証 | 同じ seed なら同じ出題順・同じ選択肢配置 | NFR-001 |

- 判定：`lib/util/shuffle.ts` 以外で乱数を使わない。
- 理由コード：`C007_nondeterministic_quiz`
